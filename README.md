# Description
A mini version of the Simon Says game is a quick and fun memory game, where players must repeat a sequence of colors or sounds in the same order as presented. 
The game starts with a single input, and each round, the sequence grows longer. The player's goal is to remember and replicate the sequence correctly, with each mistake ending the game. 
It's a simple, fast-paced challenge that tests memory and concentration.
